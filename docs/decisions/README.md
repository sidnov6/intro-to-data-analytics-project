# Decision Records

Important project choices belong here so the team can remember what was decided and why.

Copy [`000-template.md`](000-template.md), assign the next number, and use a short title, for example:

- `001-select-project-topic.md`
- `002-choose-primary-dataset.md`
- `003-lock-evaluation-plan.md`

Do not rewrite the history after results are known. If a decision changes, add a new record that supersedes the old one.
