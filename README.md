# Intro to Data Analytics — Group Project

This repository is the shared workspace for our **Intro to Data Analytics** course project. It will hold the project from idea selection through data preparation, analysis, modelling, the micropublication, and the presentation.

> **Current phase:** Use-case discovery. No topic has been selected yet.

## Start here

1. Read [the course requirements](COURSE_REQUIREMENTS.md).
2. Read [the project charter](PROJECT_CHARTER.md).
3. Add one proposal using the instructions in [`usecases/`](usecases/README.md).
4. Review proposals with the shared [scorecard](usecases/SCORECARD.md).
5. Record the final choice in [`docs/decisions/`](docs/decisions/README.md).

## Working principles

- Begin with a clear research question, not a preferred algorithm.
- Verify that the necessary data exist before choosing a topic.
- Keep raw data unchanged and document every transformation.
- Compare models with a simple baseline and an honest evaluation design.
- Keep code readable enough for every teammate to explain during Q&A.
- Report limitations and unsuccessful results; do not tune the story after seeing the test set.
- Record AI assistance and human review in [`docs/AI_USE.md`](docs/AI_USE.md).
