# Presentation

Target format from the reviewed course page:

- **20-minute presentation**
- **10-minute Q&A**

A practical 20-minute structure is:

1. Question and motivation — 2 minutes
2. Data and quality challenges — 4 minutes
3. Method and baseline — 4 minutes
4. Results — 5 minutes
5. Interpretation, limitations, and recommendation — 3 minutes
6. Conclusion — 2 minutes

The final speaking plan should give every teammate a substantive part. Everyone should be able to explain the target/unit of analysis, one cleaning decision, the baseline, the main metric, the result, and the largest limitation.

Prepare a Q&A sheet covering data provenance, missingness, leakage/bias, model choice, metric choice, robustness, ethics/privacy, reproducibility, and unsupported causal claims.
